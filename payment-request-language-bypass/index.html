Payment Request Language Bypass — third-party origin

This origin (Site B) plays the role of an unrelated third-party server in this test. There is nothing to run here directly.

Run the test from Site A: test-website-a.pages.dev/payment-request-language-bypass/

Site A's merchant page points a PaymentRequest supportedMethods URL at endpoints hosted here:

  • /payment-request-language-bypass/pmh/<token> — payment method manifest endpoint; captures the Accept-Language Brave sends from the browser process.
  • /payment-request-language-bypass/result/<token> — lets Site A read the captured header back (CORS).
  • /payment-request-language-bypass/echo — echoes the Accept-Language of a normal cross-origin fetch() (the reduced baseline).
